# 2026-07-03 Beta Patch Notes - v0.108.0 摘要

**全局机制**
- 回合结束时的充能球 [Orb] 被动效果现在会在厄运 [Doom] 结算前触发。这意味着如果你会死于自己造成的厄运（如使用精神过载 [Neurosurge] 时），但你的闪电充能球被动能在这个回合结束时击杀最后一名敌人，你现在会赢得战斗，而不再是失败。

**药水与遗物**
- **再生药水 [Regen Potion]** 调整：它的治疗效果现在会在厄运 [Doom] 结算前触发，防止玩家在特定情况下死于自我造成的厄运。
- **天命所归 [Divine Destiny]** (遗物) 加强：获得的星辰 [Star] 数量从 6 -> 7。

**铁甲战士 [Ironclad]**
- **巨像 [Colossus]** 削弱：格挡获得从 5(8) -> 4(7)。
- **绯红披风 [Crimson Mantle]** 削弱：格挡获得从 8(10) -> 7(10)。
- **彼岸咆哮 [Howl From Beyond]** 加强：伤害从 16(21) -> 18(24)。
- **预备打击 [Setup Strike]** 加强：力量获得从 2(3) -> 3(4)。

**静默猎手 [Silent]**
- **毒性爆发 [Outbreak]** 重做：“每当你施加 3 次中毒 [Poison] 时，对所有敌人造成 15 点伤害。” -> “每当你施加中毒时，对所有敌人造成 3(4) 点伤害。”
- **预判 [Anticipate]** 加强：敏捷获得从 2(3) -> 2(4)。
- **翻越撑击 [Flick-Flack]** 加强：伤害从 6(8) -> 7(9)。
- **跟踪 [Tracking]** 削弱：“虚弱的敌人受到攻击时受到双倍伤害。” -> “虚弱的敌人受到攻击时多受 50% 的伤害。”

**摄政王 [Regent]**
- **葬送 [Devastate]** 加强：伤害从 30(40) -> 35(45)。
- **护驾！！！ [GUARDS!!!]** 的仆从捐躯 [Minion Sacrifice] 衍生物削弱：格挡获得从 8(11) -> 7(10)。
- **共鸣 [Resonance]** 加强：星辰消耗从 3 -> 2。

**死灵缚者 [Necrobinder]**
- **纠缠 [Haunt]** 加强：生命流失从 6(8) -> 7(9)。
- **剥夺 [Reave]** 加强：伤害从 9(11) -> 10(13)。
- **灵魂风暴 [Soulstorm]** 加强：额外伤害从 2(3) -> 4(6)。

**故障机器人 [Defect]**
- **压缩 [Compact]** 的燃料 [Fuel] 衍生物削弱：不再抽牌；升级效果从增加抽牌数变为提供 1 点额外能量。
- **趁势打击 [Momentum Strike]** 加强：伤害从 10(13) -> 11(15)。
- **刮削 [Scrape]** 调整：不再丢弃那些因全局临时效果（如“突袭”造成的下张技能耗能为 0）而临时变为 0 费的卡牌。
- **打碎 [Shatter]** 调整：现在消耗 [Exhaust]。

**多人模式 [Multiplayer]**
- **午夜 [Midnight]** (铁甲战士攻击)：新增。稀有/12费，“造成 99(120) 点伤害。本场战斗中任何人每消耗一张牌，此牌耗能减 1。”
- **炽焰 [Blaze]** (铁甲战士技能)：新增。罕见/2费，“给予另一名玩家 5(7) 点力量。”
- **群情激愤 [Outrage]** (铁甲战士攻击)：新增。罕见/0费，“造成 9(13) 点伤害。将此牌的复制放入所有人的弃牌堆。”
- **肉盾 [Tank]** (铁甲战士) 加强并微调：“受到的敌人伤害翻倍。盟友受到的敌人伤害减半。” -> “受到的敌人伤害增加 50%。盟友受到的敌人伤害减少 50%。”
- **刀刃交响曲 [Blade Symphony]** (静默猎手技能)：新增。罕见/1费，“将 2(3) 张小刀加入所有玩家的手牌。”
- **调制 [Concoct]** (静默猎手技能)：新增。罕见/0费，“本回合另一名玩家的攻击会施加 3(4) 层中毒 [Poison]。”
- **消逝 [Fade]** (静默猎手技能)：新增。罕见/0费，“保留。本回合另一名玩家获得 6(9) 点敏捷。”
- **夹击 [Flanking]** 调整：稀有度从 罕见 -> 稀有。
- **筹划 [Plot]** (摄政王技能)：新增。罕见/1费，“下回合，所有玩家抽 2(3) 张牌。”
- **群星荟萃 [Constellation]** (摄政王技能)：新增。罕见/0费，“另一名玩家抽 1 张牌，获得 [能量]，并获得 9(12) 点格挡。”
- **幽冥之界 [Underworld]** (死灵缚者技能)：新增。罕见/2费，“本回合每当其他玩家造成攻击伤害时，施加等量的厄运。消耗。升级(移除消耗)。”
- **灵魂绑定 [Soulbound]** (死灵缚者能力)：新增。罕见/1费，“(固有)。选择一名盟友。每当你创造一个灵魂 [Soul] 时，在他们的抽牌堆加入一个灵魂。”
- **不谐合曲 [Cacophony]** (死灵缚者能力)：新增。稀有/2费，“所有玩家每抽 33 张牌，对一名随机敌人造成 66(99) 点伤害。”
- **骸骨军团 [Legion of Bone]** 调整：不再消耗 [Exhaust]。
- **休眠 [Hibernate]** (故障机器人技能)：新增。罕见/2费，“生成 2(3) 个冰霜 [Frost]。本回合，你的冰霜会为所有盟友提供格挡。”
- **一心化万 [One For All]** (故障机器人能力)：新增。稀有/1费，“所有人耗能为 0 的攻击额外造成 3(4) 点伤害。”
- **模仿学习 [Imitation Learning]** (故障机器人技能)：新增。稀有/1费，“选择另一名玩家。在他们接下来的 2(3) 次打出能力牌时，你也打出其复制。消耗 [Exhaust]。”
- **引火 [Ignition]** 调整：稀有度从 稀有 -> 罕见。
- **魔球 [The Ball]** (无色攻击)：新增。罕见/1费，“造成 10 点伤害。本场战斗中使此牌的伤害增加 15(25) 并将其给予一名随机盟友。”
- 双人模式中敌人格挡随层数的成长曲线削弱。
- **希望灯塔 [Beacon of Hope]** 削弱：耗能从 1 -> 2。

**敌人**
- **火把头融合体 [Torchhead Amalgam]** 加强：进阶 9 下伤害增加（弱撞击从 14(15) -> 14(16)；撞击从 18(19) -> 18(22)）。
