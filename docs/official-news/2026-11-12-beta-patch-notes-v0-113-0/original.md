At long last, the biggest (beta) patch yet is here!!!

Reminder that this patch is **exclusive to the beta branch of the game** as we've got some really impactful bits of content that will require lots of testing before they reach the main branch. Reminder that if you'd like to swap over to the beta branch, you can do so by right-clicking on *Slay the Spire 2* in your library and navigating to Properties -> Game Versions & Betas and selecting `public-beta` from the dropdown.

The main branch will be brought up-to-date with all content and changes in the previous, more stable beta version, v0.111.0. So don't be confused that the following content isn't there if you boot up the main branch.

Without further ado, let's take a look at all the new goodies there are to test out...

## New Character: **The Fool**

![](https://clan.fastly.steamstatic.com/images/44971832/663f1cafd2f3c84f101a6906047f3b542e437873.gif)

Wah!! The first new character for Early Access arrives! A silly musician who wields a bow! How can such a whimsical creature survive within the Spire? Why, that's up to you! We expect to make a great number of content and balance changes before the Fool is ready for the main branch. Even more importantly, be sure to have fun figuring out all the strategies and story of this gently bard. It would be foolish not to!

## New Game Mode: **Blitz**

A condensed and chaotic deckbuilding-focused mode, **Blitz** is here! The Merchant's wares feel a bit *off*, the map is gone, and Gold no longer matters?? Blitz comes with 5 levels of Ascension shared across all characters and is unlocked upon completing an Ascension run of any difficulty.

## New Game Mode: **Dread**

A brutally difficult mode for those who have reached Ascension 10 on all characters (including the new one) and are seeking the ultimate challenge! All ascension modifiers are enabled. Bosses are stronger *and* buff all enemies in their Act. Curses will also pile up as you climb the Spire. Death is expected.
