# 2026-07-17 Beta Patch Notes - v0.109.0 摘要

**全局**
- **涅奥的牺牲 [Neow's Sacrifice]** (遗物)：新增。拾取时，获得 1 瓶**龙涎香 [Ambergris]** 并将 1 张**愧疚 [Guilty]** 放入你的牌组。
  - **龙涎香 [Ambergris]** (药水)：回复 50% 最大生命值。在当前回合后进行一个额外回合。
- **寻龙尺 [Dowsing Rod]** (遗物)：新增。拾取时，将 1 张**探寻 [Dowsing]** 放入你的牌组。
- **探寻 [Dowsing]** (任务牌)：0 费。“在进入 5 个额外的 ? 房间后，将其变形为**富足 [Abundance]**。”
  - **富足 [Abundance]** (远古牌/技能)：1 费。“选择 1 张（已升级的）能力牌（3 选 1）加入你的手牌。本回合打出它不消耗能量。消耗 [Exhaust]。”
- **诺努佩佩的钻石王冠 [Nonupeipe's Diamond Diadem]** (遗物) 重做：“每当你一回合打出 2 张或更少牌时，受到的敌人伤害减半。” -> “战斗开始时获得 20 点格挡。在你的下个回合开始时格挡不会消失。”
- **奥罗波斯的沙堡 [Orobos' Sand Castle]** (遗物) 池子移动：从 池子1 -> 池子2。
- **达尔夫 [Darv]** 祝福池调整：增加多样性（会更常看到能量遗物）。
- **坦克斯的切肉刀 [Tanx's Meat Cleaver]** (遗物) 削弱：生命恢复从 9 -> 5。
- **特斯卡塔拉的玩具箱 [Tezcatara's Toybox]** (遗物) 加强：获得的遗物从 4 -> 5。
- **瓦库的小提琴 [Vakuu's Fiddle]** (遗物) 加强：抽牌数从 2 -> 3。
- **瓦库的枯爪 [Vakuu's Sere Talon]** & **卓越斗篷 [Distinguished Cape]** (遗物) 调整：交换了它们的负面效果。
- **历史课 [History Course]** (遗物) 削弱：现在只重复攻击牌，不影响技能牌。

**铁甲战士 [Ironclad]**
- **恶魔形态 [Demon Form]** 加强：力量获得从 2(3) -> 3(4)。
- **跃跃欲试 [Expect a Fight]** 加强：不再具有“本回合你无法获得额外的[能量]”的限制。
- **原始力量 [Primal Force]** 加强：巨石 [Giant Rock] 衍生物伤害从 16(20) -> 20(24)。
- **挑衅 [Taunt]** 调整：格挡获得从 7(8) -> 6(7)；稀有度从 罕见 -> 普通。
- **放血 [Bloodletting]** 调整：稀有度从 普通 -> 罕见。
- **残酷 [Cruelty]** 调整：稀有度从 稀有 -> 罕见。
- **主宰 [Dominate]** 调整：稀有度从 罕见 -> 稀有。

**静默猎手 [Silent]**
- **蜃景 [Mirage]** 重做：罕见/技能/1(0)费，“获得等同于所有敌人中毒 [Poison] 层数的格挡。消耗 [Exhaust]。” -> 罕见/技能/0费，“下回合获得 1(2) 点能量。”
- **计划妥当 [Well-Laid Plans]** 重做：罕见/能力/1费，“在你的回合结束时，保留 [Retain] 最多 1(2) 张牌。” -> 稀有/能力/1(0)费，“在你的回合结束时，你不再弃牌。”；现在也可以在多人游戏中使用。
- **专长 [Expertise]** 重做：“抽牌，直到你的手牌达到 6(7) 张。” -> “抽 2(3) 张牌。它们在本回合获得保留 [Retain]。”
- **毒性爆发 [Outbreak]** 加强：伤害从 3(4) -> 4(5)。
- **触媒 [Accelerant]** 调整：稀有度从 稀有 -> 罕见。

**摄政王 [Regent]**
- **创世之柱 [Pillar of Creation]** 重做：“每当你创造一张牌时，获得 3 点格挡。” -> “每回合你第一次创造牌时，获得 5(7) 点格挡。”
- **碰撞轨迹 [Collision Course]** 削弱：伤害从 11(15) -> 10(14)。

**死灵缚者 [Necrobinder]**
- **幻景 [Eidolon]** 重做：“消耗你的手牌。如果通过这种方式消耗了 9 张牌，获得 1 层无实体 [Intangible]。” -> “打出消耗牌堆中所有的虚无 [Ethereal] 牌。消耗 [Exhaust]。”

**故障机器人 [Defect]**
- **超能光束 [Hyperbeam]** 加强：伤害从 28(36) -> 30(38)。
- **分离 [Sunder]** 加强：伤害从 24(32) -> 26(34)。
- **化废为宝 [Trash to Treasure]** 调整：升级效果从 获得固有 -> 耗能减少 1。

**多人模式 [Multiplayer]**
- **指导 [Tutor]** (摄政王)：新增。稀有/技能/1(0)费，“另一名玩家选择其抽牌堆中的 1 张牌加入手牌。”
- **午夜 [Midnight]** 削弱：伤害从 99(120) -> 60(72)。
- **魔球 [The Ball]** 削弱：成长幅度从 +15(25) -> +10(15)。
- **刀刃交响曲 [Blade Symphony]** 削弱：耗能从 1 -> 2(1)；升级不再增加小刀的数量。
- 玩家现在几乎可以对其他玩家使用任何药水。

**敌人**
- **永世沙漏 [Aeonglass]** (BOSS) 削弱：Ebb 技能伤害从 26(32) -> 22(26)。
- **火把头融合体 [Torchhead Amalgam]** 加强：现在第一回合会使用新的“强力冲撞”技能，使其先手伤害从 18(22) -> 26(32)。
