# 感染棱柱 (Infested Prism) 机制与数值设计资料

## 一、 原版感染棱柱数据拆解 (D:\Game\Sts2Code)

> 版本 v0.109.0

### 1. 基础属性
* **生命值 (HP)**: 161 (高阶/A8+: 171)
* **初始被动**: `VitalSparkPower` (活力火花) 2 层 (A3+: 3 层)
  * 给玩家牌库中所有【技能牌】施加 `Tainted` (污染) 减益。
  * 玩家打出被污染的技能牌时，感染棱柱获得 +2 (+3) 力量。
