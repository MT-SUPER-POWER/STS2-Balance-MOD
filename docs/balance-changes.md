### 卡牌

- [x] **POWER-WITCH-FORM-01** — 女巫形态（Witch Form）与巫术虚弱（Sorcery Weak）数值平衡调整
  - 目前: 女巫形态回合开始额外抽 2 张牌；巫术虚弱减少敌人造成攻击伤害的 50%（伤害倍率 0.5）。
  - 目标: 降低女巫形态的过牌与巫术虚弱的防御强度，同时保留手牌转化与 0 费巫术牌循环的核心机制。
  - 数值:
    - 女巫形态（Witch Form）：回合开始额外抽牌由 **2 张** 调整为 **0 张（不再额外抽牌，仅保留变牌）**；手牌转化 2 张巫术牌逻辑保持不变。
    - 巫术虚弱（Sorcery Weak）：攻击伤害减免由 **50%** 调整为 **40%**（伤害倍率由 `0.5m` 调整为 `0.6m`）；掉层机制与层数逻辑保持不变。
    - 巫术打击+ / 巫术防御+：0 费、造成 9 点伤害 / 获得 8 点格挡、各抽 1 张牌、消耗属性保持不变。
    - 巫术易伤（Sorcery Vulnerable）：+75% 伤害倍率（`1.75m`）保持不变。
  - 备注: 同步更新 zhs 与 eng 的能力本地化文本及各说明文档。

### 遗物

- [x] **RELIC-DELICATE-DOLL-01** — 先古遗物精致的玩偶（Delicate Doll）拾起时永久失去 50% 生命上限
  - 目前: 拾起精致的玩偶时仅将一张已升级的【女巫形态+】加入牌组，无任何代价；女巫形态变牌逻辑保持可变任意手牌。
  - 目标: 拾起精致的玩偶时，永久失去当前生命上限的 50%（`Math.Floor(MaxHp * 0.5)`），并加入已升级的【女巫形态+】；保留女巫形态手牌转化的自由度，将高收益的门槛放在先古遗物获取时的永久血上限代价。
  - 数值: 拾起扣除永久生命上限 50%（向上/向下取整保证至少保留 1 点生命上限）。
  - 备注: 同步更新遗物本地化描述（zhs / eng 等）及相关文档（README / docs/events.md 等）。

- [x] **SETTINGS-DELICATE-DOLL-01** — 精致的玩偶与女巫形态可开关选项及文档说明同步
  - 目前: 代码已在 `BalanceModSettings` 中提供 `EnableDelicateDollCrossover`（默认开启），并在 `TanxPatch` 中进行开关判断，但 `README.md`、`README_EN.md`、`docs/events.md`、`docs/powers.md` 未完整列入 Mod 设置表格与说明，且未在卡池/遗物池中彻底过滤。
  - 目标: 在 Mod 设置中显式提供「启用方舟联动：精致的玩偶（女巫形态）」开关；当关闭时，Tanx 事件不生成精致的玩偶，同时从卡池与遗物池过滤精致的玩偶与女巫形态相关卡牌；全面同步主文档与英文文档中的 Mod 设置表格与效果说明。

- [x] **RELIC-MUTAGENIC-01** — 突变之力（Mutagenic Strength）重做为递减流失 Debuff
  - 目前: 战斗开始时获得 3 点临时力量，在第 1 回合结束时立即失去全部 3 点力量。
  - 目标: 战斗开始时获得 3 点力量，并附加 3 层 Debuff【突变衰退/力量流失】；玩家每回合结束时流失 1 点力量并扣减 1 层 Debuff，扣完 3 点后 Debuff 自动移除。
  - 数值:
    - 入场获得: +3 力量，3 层力量流失 Debuff
    - 第 1 回合结束: 失去 1 点力量（净剩 2 力量），Debuff 剩余 2 层
    - 第 2 回合结束: 失去 1 点力量（净剩 1 力量），Debuff 剩余 1 层
    - 第 3 回合结束: 失去 1 点力量（净剩 0 力量），Debuff 扣完移除
  - 备注: 流失效果为独立 Debuff，可正常与人工制品（Artifact）交互（抵挡流失效果后保留永久 +3 力量）。
