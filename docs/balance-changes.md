### 卡牌

- [x] **CARD-SYNTHESIS-01** — 移除原版卡牌：人工合成（Synthesis）
  - 目前: 人工合成作为原版故障机器人（Defect）罕见攻击牌在卡池中生成与掉落。
  - 目标: 通过 Harmony Patch 将人工合成从故障机器人卡池（`DefectCardPool`）中移除，使其不再出现于选牌奖励与商店中。
  - 数值: 不涉及数值修改（从卡池完全移除）。
  - 备注: 接入 Mod 设置项（独立开关 `C35`），支持玩家自由启闭此卡牌移除项。

- [x] **CARD-DEFRAGMENT-01** — 碎片整理（Defragment）稀有度调整为罕见（蓝卡）
  - 目前: 碎片整理在 STS2 原版中为稀有（金卡），导致集中流启动门槛过高，在长线战斗中难以成型。
  - 目标: 将碎片整理稀有度下调为罕见（Uncommon / 蓝卡），作为故障机器人充能球集中流派的基础构建支柱。
  - 数值:
    - 耗能: 1 费能力牌
    - 效果: 获得 1（升级 2）点集中
    - 稀有度: 稀有（Rare） ➔ 罕见（Uncommon）
  - 备注: 通过 Harmony Patch 动态修改 `Defragment` 的卡牌稀有度属性并正确同步卡池。

- [x] **CARD-CONSUME-01** — 新增故障机器人稀有金卡：耗尽（Consume）
  - 目前: STS2 中未包含 1 代经典卡牌【耗尽】。
  - 目标: 新增故障机器人稀有（Rare / 金卡）技能牌【耗尽】。作为高上限、高风险的成长性核心牌，可配合球位扩展（扩容、机械臂）形成数值爆发，并能被全息影像/回响形态等联动。
  - 数值:
    - 耗能: 2 费技能牌
    - 稀有度: 稀有（Rare / 金卡）
    - 未升级效果: 获得 2 点集中，失去 1 个充能球栏位。
    - 升级效果: 获得 3 点集中，失去 1 个充能球栏位。
  - 备注:
    - 提供四国语言本地化（zhs / eng / ita / rus）
    - 包含卡牌立绘（1000×760 与 500×380），使用 `image_gen` 生成
    - 遵循 `BalanceCardTemplate` 结构规范并注册至 `DefectCardPool`

### 遗物

- [x] **RELIC-INSERTER-01** — 新增故障机器人专属稀有遗物：机械臂（Inserter）
  - 目前: STS2 中未包含 1 代经典遗物【机械臂】。
  - 目标: 新增故障机器人专属稀有遗物【机械臂】。每 2 回合获得 1 个充能球栏位，为长线战斗提供持续的球位再生，与【耗尽】、【暴涨】形成资源闭环。
  - 数值:
    - 稀有度: 稀有（Rare，故障机器人专属）
    - 触发时机: 玩家回合开始时（AfterSideTurnStart）
    - 触发条件: 每 2 回合（TurnsSeen 计数器达到 2 时重置为 0）
    - 效果: 获得 1 个充能球栏位（`OrbCmd.AddSlots(Owner, 1)`）
  - 备注:
    - 提供四国语言本地化（zhs / eng / ita / rus）及风味引言（"推。拉。堆叠。重复。" / "Push. Pull. Stack. Repeat."）
    - 图标资源集成（完成 94×94、256×256 与 3px 自动外环 outline 生成）
    - 继承 `BalanceRelicTemplate` 并注册至 `DefectRelicPool`，配备计数器 UI 与闪烁激活状态

- [x] **RELIC-BLUE-CANDLE-01** — 新增罕见通用遗物：蓝蜡烛（Blue Candle）（代码与资源完成，待推送 CI 编译验收）
  - 目前: 游戏中未包含 1 代经典遗物【蓝蜡烛】。
  - 目标: 新增罕见通用遗物【蓝蜡烛】。使得原本不能被动/不能打出的诅咒牌可以被打出（0 费；原本有费用的诅咒按原费支付）；每当打出诅咒牌时，失去 1 点生命并将其消耗。
  - 数值:
    - 稀有度: 罕见（Uncommon）
    - 作用对象: 诅咒牌（Curse）
    - 打出消耗: 失去 1 点生命（非格挡减免的直接生命流失）
    - 打出结果: 该诅咒牌进入消耗堆（Exhaust）
  - 备注:
    - 提供四国语言本地化（zhs / eng / ita / rus）及引言风味文本
    - 图标资源集成（完成 94×94、256×256 与 3px 自动外环 outline 生成）
    - 接入 Mod 设置分区独立开关（R27 蓝蜡烛，支持独立启用/禁用与图鉴隔离）

- [x] **RELIC-MUTAGENIC-01** — 突变之力（Mutagenic Strength）重做为递减流失 Debuff
  - 目前: 战斗开始时获得 3 点临时力量，在第 1 回合结束时立即失去全部 3 点力量。
  - 目标: 战斗开始时获得 3 点力量，并附加 3 层 Debuff【突变衰退/力量流失】；玩家每回合结束时流失 1 点力量并扣减 1 层 Debuff，扣完 3 点后 Debuff 自动移除。
  - 数值:
    - 入场获得: +3 力量，3 层力量流失 Debuff
    - 第 1 回合结束: 失去 1 点力量（净剩 2 力量），Debuff 剩余 2 层
    - 第 2 回合结束: 失去 1 点力量（净剩 1 力量），Debuff 剩余 1 层
    - 第 3 回合结束: 失去 1 点力量（净剩 0 力量），Debuff 扣完移除
  - 备注: 流失效果为独立 Debuff，可正常与人工制品（Artifact）交互（抵挡流失效果后保留永久 +3 力量）。
