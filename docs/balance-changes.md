  - 数值: 升级前消耗且获得 3 点能量；升级后取消消耗且获得 3 点能量。

- [x] **CARD-DOWSING-REMOVE-PATCH** — 移除「探寻」（Dowsing）问号房数量补丁

  - 目标: 官方在 v0.113.0 更新中已原生将目标改为 4 个 ? 房间（且战斗问号房不触发），因此完全移除 Mod 中的 `DowsingRoomsPatch.cs`，直接采用官方原版实现。
  - 数值: 4 个 ? 房间（原版已支持）。

### 事件与遭遇

- [x] **EVENT-NEW-EVENTS-CURSE-REDUCE** — 新增事件多重诅咒数量减 1
  - 目前: v0.113.0 新增事件中，部分选项惩罚塞入过多诅咒牌：
    1. 「显秘瀑布」（WaterfallOfObviousSecrets）的「暴打」选项给予 2 张「内疚」（Guilty）。
    2. 「诺奴佩普温泉」（ThermaeNonupeipe）的「痛饮泉水」选项给予 3 张「内疚」（Guilty）。
  - 目标:
    1. 「显秘瀑布」暴打选项的「内疚」诅咒由 2 张减少至 1 张。
    2. 「诺奴佩普温泉」痛饮选项的「内疚」诅咒由 3 张减少至 2 张。
  - 数值: 显秘瀑布内疚 2 → 1；诺奴佩普温泉内疚 3 → 2。
  - 备注: 单张诅咒选项（如督军圣堂给予 1 张笨拙、酷刑博物馆给予 1 张随机诅咒）保留 1 张诅咒的设定不变。

- [x] **CARD-WITCH-FORM-REWORK** — 重构先古能力牌「女巫形态」（Witch Form）
  - 目前: 3 费，虚无，升级后获得固有。打出获得 1 层女巫形态并结束回合；能力效果为每回合开始提示选择手牌中 2 张牌蜕变为升级后的巫术打击+与巫术防御+。
  - 目标:
    1. 费用与词条: 未升级 3 费（移除固有与虚无）；升级后 2 费，获得「固有」（无虚无）。默认未升级。
    2. 打出时效果: 移除「结束回合」；打出时立即将当前手牌中所有的基础「打击」与「防御」分别蜕变为升级后的「巫术打击+」与「巫术防御+」。
    3. 能力持续效果（女巫形态）: 移除回合开始选牌蜕变效果，改为常驻 Buff：每回合开始多抽 1 张牌（ModifyHandDraw +1）。
  - 数值: 未升级 3 费 / 升级后 2 费；每回合抽牌 +1。
  - 备注: 需同步更新卡牌与能力多语言文本（zhs/eng/ita/rus）。

    3. 拾起变牌（非战斗）: 拾起时弹出牌组选牌界面，选择 2 张牌分别蜕变为升级后的「巫术打击+」与「巫术防御+」。
    4. 战斗被动: 保持第 1 回合开始对所有敌人施加 2 层易伤与 2 层虚弱不变。
  - 数值: 最大生命上限 -25%；所有敌人 2 层易伤、2 层虚弱。
  - 备注: 需同步更新遗物多语言文本（zhs/eng/ita/rus）。

### 事件与遭遇

- [x] **ENCHANT-ECHO-WHIRLPOOL** — 新增「回响」附魔并替换第 1 幕「旋转漩涡」事件奖励
  - 目前: 原版第 1 幕事件「旋转漩涡」（SpiralingWhirlpool）仅允许对基础「打击」或「防御」附魔「涡旋」（Spiral，重放 1 次）。
  - 目标:
    1. 新增附魔「回响」（EchoEnchantment）：被附魔的卡牌每回合能够重放 1 次（对齐「华彩」语法规则，支持 X 费卡牌）；可附魔常规攻击牌、技能牌与能力牌（排除状态牌、诅咒牌及已附魔牌）。
    2. 卡牌展示与提示：牌面底端附带紫色关键文本标记（如「回响。」），卡牌悬停与事件选项显示对应 HoverTip 与说明。
    3. 资源配图：采用原版「回响形态」能力图标（`echo_form_power.png`）作为附魔图标。
    4. 事件改造：Patch 原版「旋转漩涡」（SpiralingWhirlpool），将其选项 1 从「涡旋」附魔替换为「回响」附魔，事件出现前提同步适配为牌组中存在符合回响条件的卡牌，保留选项 2 恢复生命值。
    5. 全套辅助要素：补齐四国语言（zhs/eng/ita/rus）本地化、附魔预览 VFX、音效与存读档序列化支持。
- [x] **EVENT-MASK-BANDITS** — 调整第 2 幕事件「面具强盗」（MaskedBandits）触发约束
  - 目前: 限制第 2 幕且 TotalFloor >= 23。由于 STS2 线性事件队列机制，前 6 层踩中问号房会导致事件被永久跳过丢弃，实际极难遭遇。
  - 目标: 对齐原版「灯火钥匙」（TheLanternKey）事件约束，移除 TotalFloor 限制，仅保留第 2 幕且队伍未持有红面具。
- [x] 重构第 3 幕事件「红面具大人之墓」（TombOfLordRedMask）：限制仅持有「红面具」时出现，重构为强盗三人组缅怀致敬选项（罗密欧 222 金币、尖刺的双刺、巨熊的皮甲）
