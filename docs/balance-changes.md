## 待办项

### 卡牌

- [x] **CARD-06** — 撤销「放松」（Relax）格挡增强补丁
  - 目前: Mod 存在 `RelaxBlockPatch` 将格挡值提升至 18（升级 20）。
  - 目标: 注释并撤销该补丁，保持官方原版属性。

- [x] **CARD-07** — 调整「创世之柱」（Pillar of Creation）格挡数值为 3/4
  - 目前: 官方对创世之柱进行了更新，Mod 先前的 Patch 改写了 Power 每张卡牌触发逻辑。
  - 目标: 移除先前的 Power 触发 Patch，仅将卡牌格挡数值设为 3（升级后 4）。

- [x] **CARD-08** — 调整「巨镰」（The Scythe）初始伤害为 16 点
  - 目前: Mod 先前的补丁将初始伤害改为了 20 点；官方更新将伤害成长从 4(5) 提高至 5(7)。
  - 目标: 将巨镰初始伤害调整为 16 点，配合官方增加的成长机制。

- [x] **CARD-09** — 回调「火箭飞拳」（Rocket Punch）为降至 0 费
  - 目前: 官方 v0.110.0 将火箭飞拳削弱为每生成 1 张状态牌减 1 费。
  - 目标: 增加 Patch 恢复回调之前的效果——每当生成状态牌时，火箭飞拳的耗能在下一次打出前直接降至 0 费。

- [x] **CARD-10** — 调整「华丽收场」（Grand Finale）升级效果为 X+2 且不增加伤害
  - 目前: 基础版打出条件为抽牌堆张数 ≤ X (当前能量)。
  - 目标: 华丽收场升级后打出条件扩宽为抽牌堆张数 ≤ X + 2（当前能量 + 2），且升级不再增加伤害。


### 遗物

- [x] **RELIC-02** — 重构「烘焙手套」（Toasty Mittens）消耗手牌与 Skip 逻辑
  - 目前: 回合开始自动从抽牌堆消耗 1 张牌并获得 1 点力量。
  - 目标: 改为允许玩家在手牌中选择 1 张卡牌消耗（包含 Skip 跳过选项）；只有成功消耗了 1 张手牌时才获得 1 点力量，选择 Skip 则不获得力量。

- [x] **RELIC-03** — 回调「图章戒指」（Signet Ring）获得的金币为 999
  - 目前: 官方 v0.110.0 更新将图章戒指获得的金币从 999 降低到 888。
  - 目标: 增加 Patch 将图章戒指获得的金币回调恢复为 999。
