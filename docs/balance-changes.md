## 待办项

### 卡牌

<!-- - [ ] **CARD-01** — -->

- [x] **CARD-01** — 回调魔球 [The Ball] 成长幅度
  - 目前: 成长幅度为 +10（升级后 +15）。
  - 目标: 回调为 +15（升级后 +20）。
  - 数值: +10（15） -> +15（20）。

- [x] **CARD-02** — 回调触媒 [Accelerant] 稀有度
  - 目前: 稀有度为罕见。
  - 目标: 回调为稀有。

- [x] **CARD-03** — 回调计划妥当 [Well-Laid Plans] 效果
  - 目前: 稀有能力牌，1（0）费；回合结束时不再弃牌。
  - 目标: 罕见能力牌，1 费；回合结束时保留最多 1（2）张牌。
  - 备注: 保留其在多人游戏中可用的支持；未选择保留的手牌会正常弃置。

- [x] **CARD-04** — 调整华丽收场 [Grand Finale] 效果
  - 目前: 0 费，抽牌堆有 0 张牌时才可以打出。
  - 目标: 改为 X 费，抽牌堆的牌数小于或等于 X 时才可以打出。
  - 备注: 伤害等效果保持不变。

- [x] **CARD-05** — 调整巨镰 [The Scythe] 初始伤害
  - 目前: 2 费稀有攻击牌，消耗；造成 13 点伤害，每次打出后此牌伤害永久增加 4 点（升级后 5 点）。
  - 目标: 初始伤害改为 20 点。
  - 备注: 费用、稀有度、消耗与每次打出的成长数值保持不变。

### 遗物

<!-- - [ ] **RELIC-01** — -->

- [x] **RELIC-01** — 回调历史课 [History Course] 效果
  - 目前: 只重复攻击牌，不影响技能牌。
  - 目标: 恢复为同时影响攻击牌与技能牌。

- [x] **RELIC-02** — 回调诺努佩佩的钻石王冠 [Nonupeipe's Diamond Diadem] 效果
  - 目前: 战斗开始时获得 20 点格挡；下个回合开始时格挡不会消失。
  - 目标: 每当一回合打出 2 张或更少牌时，受到的敌人伤害减半。

- [x] **RELIC-03** — 调整灵魂契约 [Soul Contract] 获取方式
  - 目前: 先古遗物；拾起时扣除最大生命上限 10%，选择牌组中的 1 张有消耗的牌，永久去除其消耗属性。
  - 目标: 改为仅在商店出售的遗物；拾起时不再扣除最大生命上限。
  - 备注: 保留选择牌组中 1 张有消耗的牌，永久去除其消耗属性的效果。
